# Elton Chipuka — Portfolio

Personal portfolio site for Elton Chipuka, full-stack software developer in Harare, Zimbabwe:
ERP platforms, workflow automation, microservices, and mobile apps.

Built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion. All content lives in
`src/data/` (projects, experience, skills), so updating the site is a data edit.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build     # outputs dist/
npm run preview   # serve the production build
```

The build is a static site and can be deployed to Vercel, Netlify, or GitHub Pages.
